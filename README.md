## 🛠️ Stack habitual

- **Backend**: Python (FastAPI, Flask) · Node.js (Baileys, whatsapp-web.js)
- **IA local**: Ollama (qwen2.5vl para visión, qwen2.5:7b para texto) · Whisper
- **Datos**: SQLite → PostgreSQL · Pydantic para validación
- **UI**: Next.js · HTML/CSS/JS ligero · ReportLab para PDFs
- **Deploy**: Netlify · Railway · instaladores Windows para clientes on-premise

Diferenciador: **todo el pipeline de IA corre 100 % local** en la máquina del cliente. Cero API keys de terceros, cero datos en cloud extranjero.
